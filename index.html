Accès à l'application

L'authentification fonctionne sans internet : elle est vérifiée dans ce téléphone. Les actions de cette section demandent ton mot de passe actuel.

Code PIN rapide (facultatif)

Le code PIN évite de retaper le mot de passe après un verrouillage. Le mot de passe est redemandé 12 heures après la dernière connexion.

Verrouillage automatique

L'appli se verrouille après un moment sans toucher l'écran, et dès que tu la réduis. Elle ne se verrouille pas quand tu pars vers WhatsApp, le téléphone ou le partage depuis l'appli, ni quand tu actualises la page.

Sauvegarde des fiches

Les fiches sont enregistrées dans ce téléphone. Une sauvegarde est un fichier nommé par mois, par exemple sauvegarde_novembre_2026.json, rangé dans les Téléchargements. Garde-en une copie ailleurs (WhatsApp, Drive, ordinateur).

Copies automatiques

Chaque mois, l'appli garde toute seule une copie des fiches dans le téléphone (les 3 derniers mois). Elles servent en cas d'erreur de suppression ou de modification.

Sauvegarde automatique en ligne

Chaque jour où le téléphone a internet, l'appli envoie une copie dans un dépôt GitHub privé, dans le dossier sauvegardes (créé automatiquement), avec le fichier du mois : sauvegardes/sauvegarde_novembre_2026.json. GitHub garde l'historique des versions.
